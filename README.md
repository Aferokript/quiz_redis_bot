# Боты для викторины в телеграмм и вконтакте

Боты проводят викторину в диалоге с пользователем. Вопросы и ответы они берут из файла quiz-question. Вопросы и ответы разделены двумя переносами строк. Логика разделения вопросов и ответов представлена в файле `procces_quiz.py`

## Redis

Данные пользователя берутся из базы данных Redis. Это нерелационная база данных, в которой данные хранятся в оперативной памяти, нежели в виде таблицы. Это позволяет использовать таблицу быстрее, нежели обычную релеационную, из который данные достаются/записываются командами языка SQL. Боты в ходе работы неоднократно обращаются к ней для чтения информации которую записал пользователь или чтобы достать вопрос с ответами.

БД поддерживается только на ОС Linux. Инструкцию по установке можно найти на их офф.сайте [redis](https://redis.io/)


## procces_quiz.py

Как я уже говорил выше, вопросы и ответы разделены двумя переносами строк. Функция в данном файле разделяет вопросы с ответами и возвращает их . Это позволяет доставать вопросы и ответы в коде с ботами и проверять ответ пользователя

## Зависимости 

В данном проекте использовались следующие библиотеки:
- `vk_api==11.10.1` — для работы с VK API (LongPoll, отправка сообщений). Это основной пакет для VK-бота.
- `python-telegram-bot==13.0` — для Telegram-бота
- `redis==8.1.0` — для подключения к базе данных Redis (хранение ответов, счётчиков).
- `python-dotenv==1.2.4` — для загрузки токенов из файла .env.

## Переменные окружения 

Необходимы следующие переменные:

1. `TG_TOKEN` - Телеграмм токен от отца ботов. Ищите в телеграмме botfather и у него получаете токен
2. `VK_GROUP_TOKEN` - Токен для вк группы. Получается в настройках группы. Настройки - дополнительно - работа с API - создать. ( Не забудьте только потом разрешить отправку сообщений в нижнем разделе )

Чтобы вы могли записать данные токены, создайте файл .env в каталоге и пропишите туда переменные окружения следующий образом ПЕРЕМЕННАЯ=ВАШ_ТОКЕН

## Установка

Python 3.10+ уже должен быть установлен на вашем компьютере. Скачивайте архив, открывайте его в вашем редакторе кода и пропишите команду:
```pip install -r requirements.txt```. Команда установит все необходимые зависимости, которые я описал выше

Дальше открываем терминал и пишем ``` python tg-quiz-bot.py``` или если хотите запустить вк бота: ```python vk-quiz.bot.py```
